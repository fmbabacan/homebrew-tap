# Homebrew Tap

Homebrew distribution for [FolioFold](https://github.com/fmbabacan/FolioFold), a native, privacy-focused PDF and structured document workspace for macOS.

## Install

```shell
brew install --cask fmbabacan/tap/foliofold
```

FolioFold provides architecture-specific, Developer ID-signed and Apple-notarized downloads for Apple Silicon and Intel Macs.
